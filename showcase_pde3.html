1. KAN Solver for Free-Boundary Value Problems and Time-Dependent Stefan Problems

Project Overview

This project studies a KAN-based physics-informed neural solver for a moving-boundary parabolic PDE. The numerical experiment learns both the time-dependent solution field and the moving free surface simultaneously.

The main example is the two-dimensional one-phase Stefan problem. The goal is to approximate the time-dependent solution \(u(x_1,x_2,t)\) and the moving free boundary \(s(x_2,t)\).

\[ u = u(x_1,x_2,t), \qquad s = s(x_2,t). \]

The full computational space-time domain is

\[ (x_1,x_2,t) \in [0,2.25]\times[0,1]\times[0,1]. \]

The physical moving domain is determined by the free surface:

\[ \Omega(t) = \left\{ (x_1,x_2): 0 < x_1 < s(x_2,t),\; 0 < x_2 < 1 \right\}, \qquad 0 \leq t \leq 1. \]

A representative heat-equation residual for the learned solution \(u_{\mathrm{KAN}}\) is

\[ \mathcal{R}_{\mathrm{PDE}}(x_1,x_2,t) = \partial_t u_{\mathrm{KAN}} - \Delta u_{\mathrm{KAN}}, \qquad (x_1,x_2)\in\Omega(t). \]

2. Methodological Workflow

Problem Formulation → Model → Training → Approximation

The project pipeline is summarized as a four-stage scientific machine-learning workflow. Each stage corresponds to a mathematical or computational component of the Stefan solver.

1

Problem Formulation

Define \(\Omega(t)\), the heat equation, boundary data, interface condition, and Stefan free-boundary condition.

2

Model

Use \(u_{\mathrm{KAN}}(x_1,x_2,t)\) for the solution and \(\hat{s}(x_2,t)\) for the learned interface.

3

Training

Minimize a composite loss combining PDE residuals, initial data, boundary data, interface loss, and Stefan loss.

4

Approximation

Evaluate \(u_{\mathrm{KAN}}\), compute error metrics, and compare \(\hat{s}\) against the exact free surface.

4. Training and Approximation Details

Physics-Informed Losses and Numerical Outputs

The solver is trained by minimizing residual losses associated with the governing PDE, boundary and initial conditions, and moving-boundary constraints.

A typical composite physics-informed loss has the form

\[ \mathcal{L} = \lambda_{\mathrm{PDE}}\mathcal{L}_{\mathrm{PDE}} + \lambda_{\mathrm{IC}}\mathcal{L}_{\mathrm{IC}} + \lambda_{\mathrm{BC}}\mathcal{L}_{\mathrm{BC}} + \lambda_{\Gamma}\mathcal{L}_{\Gamma} + \lambda_{\mathrm{Stefan}}\mathcal{L}_{\mathrm{Stefan}}. \]

Physics-Informed Loss Components

  • PDE residual loss \( \mathcal{L}_{\mathrm{PDE}} \) in the moving physical domain.
  • Initial-condition loss \( \mathcal{L}_{\mathrm{IC}} \) at \(t=0\).
  • Boundary-condition loss \( \mathcal{L}_{\mathrm{BC}} \) on fixed boundaries.
  • Interface loss \( \mathcal{L}_{\Gamma} \) on the moving free boundary.
  • Stefan-condition loss \( \mathcal{L}_{\mathrm{Stefan}} \) controlling interface evolution.

Numerical Outputs

  • Approximate solution \(u_{\mathrm{KAN}}(x_1,x_2,t)\).
  • Pointwise absolute error \( |u_{\mathrm{KAN}}-u_{\mathrm{exact}}| \).
  • Training logs for total and component losses.
  • Relative errors \( \|u_{\mathrm{exact}}-u_{\mathrm{KAN}}\|_2/\|u_{\mathrm{exact}}\|_2 \) and \(L^\infty\) error.
  • Predicted free surface \(\hat{s}(x_2,t)\) compared with the exact interface \(s(x_2,t)\).
