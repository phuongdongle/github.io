1. Project Overview

The project studies a neural approximation framework for a moving-boundary parabolic PDE. The numerical experiment learns the solution field and the free surface simultaneously.

The main example is the two-dimensional one-phase Stefan problem. The goal is to learn the time-dependent solution

u(x1, x2, t)

together with the moving free boundary

s(x2, t).

The computational domain is

(x1, x2, t) ∈ [0, 2.25] × [0, 1] × [0, 1],

with the moving physical domain defined by

0 < x1 < s(x2, t),   0 < x2 < 1,   0 ≤ t ≤ 1.

2. Methodological Workflow

The project pipeline can be summarized as a four-stage scientific machine-learning workflow: problem formulation, model construction, physics-informed training, and numerical approximation.

1

Problem Formulation

Define the Stefan problem, moving domain, heat equation, boundary conditions, interface condition, and Stefan condition.

2

Model

Use a KAN-based neural representation for the solution field and a separate approximation for the free surface.

3

Training

Minimize a composite physics-informed loss including PDE residual, initial, boundary, interface, and Stefan-condition losses.

4

Approximation

Evaluate the learned solution, compute relative errors, and compare the predicted free boundary against the exact surface.

4. Training and Approximation Details

The solver is trained by minimizing residual losses associated with the governing PDE and the moving-boundary constraints.

Physics-Informed Loss Components

  • Heat-equation residual in the moving physical domain.
  • Initial-condition loss at the initial time.
  • Boundary-condition losses on fixed boundaries.
  • Interface condition on the moving free boundary.
  • Stefan free-boundary condition controlling interface evolution.

Numerical Outputs

  • Approximate solution surface uKAN(x1, x2, t).
  • Pointwise absolute error against the exact solution.
  • Training logs for total and component losses.
  • Relative L2 and L∞ errors over training.
  • Predicted free surface compared with the exact interface.

5. Summary

This showcase demonstrates how a KAN-based physics-informed solver can be used to learn a time-dependent free-boundary PDE. The formulation combines a neural approximation of the solution field with loss terms that encode the PDE, boundary data, interface constraint, and Stefan condition.
